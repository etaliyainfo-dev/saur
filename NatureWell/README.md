# NatureWell Shopify OS 2.0 Theme

NatureWell is a Shopify Online Store 2.0 theme inspired by a wellness-first storefront layout.

## Installation

1. Copy the `NatureWell` folder into your Shopify theme project.
2. Zip the folder contents (not the folder itself) and upload via **Online Store > Themes > Add theme > Upload zip file**.
3. In the theme editor:
   - Configure the **Header menu**.
   - Assign collections for each `Featured collection` section.
   - Add hero and category imagery.
   - Configure footer links and icon grid content.
4. Create a page using template `page.wishlist` for Wishlist support.

## Included features

- Sticky header + announcement bar
- Category icon carousel row
- Configurable hero section
- Multiple featured collection styles (grid/category/showcase)
- AJAX cart drawer with quantity update
- LocalStorage wishlist + wishlist page
- Collection filtering UI shell + sorting + pagination
- Product gallery and mobile sticky add-to-cart

## Notes

- Uses only vanilla JS and theme assets.
- All section images are lazy-loaded.
- Accessibility includes focus states and ESC support for drawers.
